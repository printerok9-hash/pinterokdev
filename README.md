# Pinterok frontend

The Next.js application for Pinterok. See the [project README](../README.md) for local startup, admin credentials, database setup, SMTP, Calendly and deployment configuration.

```powershell
npm.cmd run dev
npm.cmd run lint
npm.cmd run typecheck
npm.cmd run build
npm.cmd run test:e2e
```

The Express API must run separately. The repository root `npm.cmd run dev` command starts the full local stack.
